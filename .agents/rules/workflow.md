# Regras de Workflow

## 1. Sempre subir para o GitHub
- Ao finalizar qualquer modificação solicitada pelo usuário, faça commit e push imediatamente para o GitHub (`git add`, `git commit -m "..."`, `git push origin main`).
- Nunca deixe alterações pendentes localmente sem sincronizar com o repositório remoto.

## 2. Nunca tirar Prints / Screenshots dos Sites
- Não tire prints nem capturas de tela do site.
- Não execute scripts de Playwright/Puppeteer/Selenium para tirar screenshots.
- Respostas e validações devem ser imediatas, focadas no código e sem atrasar o serviço com renderização ou capturas de imagem.
