# Regras de Desenvolvimento e Workflow

## 1. Sempre subir para o GitHub
- Ao concluir alterações, realizar o commit e push para o repositório remoto (`git push origin main`).

## 2. Nunca tirar Prints / Screenshots dos Sites
- Não executar scripts para tirar prints/screenshots (Playwright, Puppeteer, etc.).
- Validações devem ser feitas diretamente no código e de forma rápida, sem atrasar o serviço.
